# 🎓 CareerAI – Smart Guidance & Skill Recommendation System

## 📌 Project Overview

**CareerAI – Smart Guidance & Skill Recommendation System** is an AI-based career guidance application designed to help students and job seekers choose suitable career paths based on their **skills, interests, and career goals**.

The system provides personalized career recommendations and suggests the important skills that users need to develop for their selected career.

## 🎯 Objectives

* Provide personalized career guidance.
* Recommend suitable career paths based on user interests and skills.
* Identify skill gaps.
* Suggest skills that users should learn.
* Provide career roadmaps for different job roles.
* Help students make better career decisions.
* Make career guidance simple and accessible.

## ✨ Key Features

### 👤 Career Profile

Users can provide information about:

* Skills
* Interests
* Education
* Career preferences

### 🤖 Smart Career Recommendation

The system analyzes the user's profile and recommends suitable career options.

### 🧠 Skill Recommendation

The application identifies important skills required for a selected career and recommends skills the user can learn.

### 🗺️ Career Roadmap

Users can view a step-by-step roadmap for their chosen career.

Example:

**Python Developer**

```text
Python Basics
      ↓
Data Structures
      ↓
SQL & Databases
      ↓
Web Development
      ↓
Projects
      ↓
Internship
      ↓
Python Developer
```

### 📚 Learning Guidance

The system helps users understand what technologies and skills they should learn to move toward their career goal.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project folder

```bash
cd CareerAI
```

### 3. Install required packages

```bash
pip install -r requirements.txt
```

If you don't have a `requirements.txt` file yet:

```bash
pip install streamlit
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
